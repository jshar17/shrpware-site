# WavePlume — Claude handoff

Everything Claude needs is in this folder.

## Use these files

- `assets/WavePlume-icon-master.png` — canonical product icon source
- `assets/WavePlume-hero-card.png` — 2048 × 768 welcome/store hero graphic
- `assets/macOS/WavePlume.icns` — macOS application icon
- `assets/windows/WavePlume.ico` — Windows application and installer icon
- `assets/png/` — PNG exports from 16 to 1024 px

## Brand rules

- Product name: **WavePlume™** on first public/marketing use; **WavePlume** in
  normal UI copy afterward.
- Tagline: **Every wave becomes a word.**
- Publisher: **WavePlume by ShrpWare™**
- Use the blue/cyan plume-wave product icon. Do not use WaveQuill, a literal
  quill, pen, ink nib, handwriting, flying letters, or the old waveform icon.
- Do not recolor the WavePlume icon acid green; that color belongs to the
  ShrpWare publisher brand.
- Use the wide hero card only in wide welcome, marketing, About, or store
  placements—not as a square app icon.

For the full website-source version, see
`docs/WAVEPLUME-APP-HANDOFF.md`.
